# Sdk

SDK oficial de CosmicOS: el kit para desarrollar apps `.sps`.

| Crate | Qué es |
|---|---|
| `cosmic-sdk` | Biblioteca para apps de terceros |

La interfaz recomendada es Qt6; GTK4 solo para apps básicas.

## Licencia

LGPL-3.0-or-later, para que las apps de terceros puedan usarlo sin ceder su propio código.
